# Zone of Information — Free Website

## Included
- Mobile-friendly bilingual (Urdu + English) homepage
- Jobs, Education, Technology and General Knowledge categories
- Example article cards, category filters and search
- About and contact sections
- Plain HTML, CSS and JavaScript (no paid dependencies)

## Preview locally
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a public repository, for example `zone-of-information`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, select Deploy from a branch, choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site; it will show you the public URL.

## Before publishing
- Replace demo articles with current, verified information.
- Add your real contact email / WhatsApp link.
- The contact form is a front-end demo; connect it to a form service or backend for reliable submissions.
- Add a privacy policy if you collect visitor information.
